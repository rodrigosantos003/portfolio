# Portfolio

## [Visit](https://rodrigo-santos.pt)

This is my personal portfolio, built with Next.js. It showcases my projects, skills, and experience in software engineering.
The website is designed to be responsive and user-friendly, providing visitors with an easy way to learn more about me and my work.

## Tech stack

- **Next.js 16** (App Router) and **React 19**, written in JavaScript
- **CSS** in per-component stylesheets, with **Inter** and **Fira Code** loaded through `next/font`
- **next/image** and **Sharp** for optimized images
- **Lenis** for smooth scrolling
- **Lucide** for icons
- **Vercel Analytics** and **Speed Insights**, loaded only after cookie consent
- **ESLint** with `eslint-config-next`
